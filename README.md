# 光亮时刻 · Light Moment

> 让每一个「想变好」的瞬间，都被自己看见。

一个面向大学生的自我成长陪伴服务系统，也是《设计思维导引》课程的结课项目。

## 这是什么

「光亮时刻」不做打卡督促。它记录那些容易被自己忽略的微小进步：今天早睡了二十分钟、今天第一次说出"我需要帮忙"、今天什么都没做成但也撑过来了。这些瞬间被收进一个「解忧罐」，在你怀疑自己的时候，替你记得。

设计上刻意避开了"连续打卡天数""排行榜""目标完成率"这类把成长变成考核的机制，转而用微光、解忧罐、陪伴对话这些更轻的方式，让人愿意回来第二次。

## 在线体验

打开 `https://jin085953-jpg.github.io/guangliang-moment/` 即可，无需注册。

- 首次进入可以点「先看看示例账号」，也可以自己起名字开始
- 建议用手机浏览器打开，体验更接近真实产品形态
- 所有数据只存在你自己的浏览器里，不上传任何服务器

## 功能

| 模块 | 说明 |
| --- | --- |
| 今日微光 | 每天推一件小事，按当天心情调节任务强度；连续三天低落时自动取消任务，改为呼吸引导 |
| 对话陪伴 | 有上下文的倾听，会记得你上次聊起过的事，不在同一个话题上重复提问 |
| 成长记录 | 记录可回头编辑，跨天回来会看到一句接续；第一次记录会收到一条反馈 |
| 心情趋势 | 7 天 / 30 天曲线，能看出星期节律；样本不足时明确标注"不下结论" |
| 自我认知雷达 | 六维评分，按记录内容真实统计，并标出每个维度的样本量 |
| 隐私与安全 | 可选密码加密本地数据，支持导出 / 导入备份，忘记密码可用备份恢复 |

## 技术说明

单文件 HTML，无框架、无外部依赖、无后端。数据存于浏览器 localStorage；开启密码后使用 AES-GCM 加密整体存储，密钥由 PBKDF2 从密码派生（SHA-256，15 万次迭代），密码本身不落盘。直接用浏览器打开 `index.html` 即可离线运行。
